Photosynthesis converts light energy into chemical energy. In the light-dependent reactions, which take place in the thylakoid membranes, water molecules are split, releasing oxygen, protons and electrons. The electrons pass along a chain of carrier proteins, and the energy they lose is used to pump protons across the membrane. The resulting gradient drives the enzyme ATP synthase. In the second stage, known as the Calvin cycle, the ATP and NADPH produced earlier are used to fix carbon dioxide into three-carbon sugars. A single turn of the cycle fixes one molecule of carbon dioxide, so six turns are needed to produce one molecule of glucose.

To compute the median of a list, sort it first and then take the middle element. If the list has an even number of elements, the median is the average of the two middle values. In Python this can be written as follows:

def median(values):
    ordered = sorted(values)
    n = len(ordered)
    if n == 0:
        raise ValueError("median of an empty list")
    mid = n // 2
    if n % 2 == 1:
        return ordered[mid]
    return (ordered[mid - 1] + ordered[mid]) / 2

Sorting costs O(n log n) time. A selection algorithm such as quickselect finds the median in O(n) expected time, which matters when the list is very large, but for a few thousand values the difference is negligible and the sorted version is easier to read.

In a relational database, an index speeds up lookups at the cost of slower writes and extra storage. A B-tree index keeps keys in sorted order, so it supports range queries as well as equality tests. A hash index supports only equality, but a lookup takes constant time on average. Choosing which columns to index depends on the queries the application actually runs. An index on a column with few distinct values, such as a boolean flag, is rarely useful, because the database still has to read a large fraction of the table. A composite index on two columns helps a query that filters on both, or on the first alone, but not one that filters only on the second.
